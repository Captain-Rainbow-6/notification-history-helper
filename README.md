# 历史通知助手 / Notification History Helper

打开 Android 系统历史通知，并添加一键直达的桌面快捷方式。适用于 Android 11 及以上系统；本 App 不读取、保存或上传消息。

Open Android's system notification history and add a home screen shortcut for direct access. Requires Android 11 or later. This app does not read, store, or upload messages.
